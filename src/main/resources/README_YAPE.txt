INSTRUCCIONES PARA AGREGAR CÓDIGO QR DE YAPE
==============================================

1. Coloca tu imagen del código QR de Yape en esta carpeta
2. El archivo debe llamarse exactamente: yape_qr.png
3. Formatos soportados: PNG, JPG, JPEG
4. Tamaño recomendado: 512x512 píxeles máximo

Una vez que agregues la imagen, compila el proyecto:
cd /home/fabricioyv/IdeaProjects/RankedDiscord
mvn clean package

¡Y listo! El comando !yape funcionará perfectamente.
